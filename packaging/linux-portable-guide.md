# Formix 格式转换通 · Linux 压缩版使用说明

## 解压并启动

1. 在文件管理器中解压整个 `.tar.gz` 文件。
2. 将解压得到的 `linux-x64-app` 文件夹移到个人目录中准备长期使用的位置，例如 `~/Applications/`。ARM64 版本的目录名为 `linux-arm64-app`。
3. 在这个文件夹里打开终端，运行：

   ```sh
   ./Formix
   ```

压缩版自带 Python 和 FFmpeg。以普通用户身份启动即可。移动软件时请移动整个文件夹，保留启动器旁的 `python/`、`formix/` 和 `vendor/`。

如果提示“权限不够”，请在当前目录运行 `chmod u+x ./Formix` 后重试。如果仍无法执行，请确认解压位置允许执行程序，并使用 Linux 的归档管理器或 `tar -xzf 文件名.tar.gz` 重新解压原包。

## 首次转换

添加文件，选择目标格式，核对“保存到”（Save to）的路径，再开始处理。使用需要额外引擎的图片或文档功能时，按提示进入设置下载 libvips 或 LibreOffice。需要识别扫描件或图片中的文字时，在设置中选择并下载相应的 OCR 模型。

## 更新与备份

收到更新提示后，在软件内确认更新。更新器会在当前解压目录替换程序文件并重新启动。请保持该目录可写，并为下载新版和展开临时文件预留磁盘空间。

- **界面设置**通常保存在 `~/.config/Formix/Formix.conf`。如果设置了 `XDG_CONFIG_HOME`，请在该目录的 `Formix/` 下查找。
- **已下载模型**通常在解压目录的 `models/` 中。可通过设置页的“打开模型目录”确认实际位置。迁移到另一台电脑时，请同时备份设置文件和实际模型目录。
- **转换结果**位于各任务选择的输出目录。备份时以“保存到”显示的路径为准。

## 启动失败或更新失败

从终端运行 `./Formix` 可以直接看到启动错误。反馈问题时，请附上系统版本、CPU 架构（`uname -m`）、压缩包文件名及对应日志：

| 情况 | 查看位置 |
| --- | --- |
| 程序已开始运行后出错 | 解压目录下 `logs/` 中本次启动对应的日志 |
| 从桌面打开时闪退 | `~/.local/state/Formix/logs/launcher.log`（若已生成） |
| 自动更新失败 | `~/.local/state/Formix/logs/updater.log` |

如果设置了 `XDG_STATE_HOME`，后两项在该目录的 `Formix/logs/` 下。
